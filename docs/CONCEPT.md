# Concept

The Lanyard Archive is a personal exhibition of physical conference and meetup badges collected across London. Digital objects should retain the original artwork, dimensions, colours and visible signs of how they were made and worn.

Phase 1 proved the close-up interaction with one card, clip and fabric strap. Visitors can pick it up, let it swing and turn it over.

Phase 2 tests a short exhibition with fifteen stops and one reusable object viewer. Each stop features one badge in a shared 3D space. In focus, the record gives the event, date, venue, pass type, dimensions and a personal note.

The exhibition features Breakpoint 2026, the Solana electronic badge, Houdini HIVEalt London 2026, the Git Nation crew pass, CityJS London 2026, CampAI, DDX London 2026, BrainStation, Flower AI Summit 2026, droidcon London 2025, SEV0, Ship LDN, AI DevCon, RNLConf and design+AI. The full collection, category chapters, maps, timelines, recaps, accounts and a database remain outside this prototype.
